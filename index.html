🍕 Сложение и вычитание дробей
  1. Найди общий знаменатель (одинаковое число внизу).
  2. Найди дополнительные множители (общий разделить на старый).
  3. Умножь числитель и знаменатель на этот множитель.
  4. Сложи или вычти только числители (числа сверху).
12 + 13 = 36 + 26 = 56
✖️ Умножение дробей
  1. Умножаем числитель на числитель.
  2. Умножаем знаменатель на знаменатель.
  3. Сокращаем результат (делим верх и низ на одно число).
25 × 34 = 620 = 310
➗ Деление дробей
  1. Переворачиваем вторую дробь (меняем верх и низ местами).
  2. Заменяем знак деления на умножение.
  3. Умножаем и сокращаем.
12 ÷ 34 = 12 × 43 = 46 = 23
⚖️ Пропорции (уравнения с дробями)
Используем правило «Крест-накрест»: произведение крайних равно произведению средних.
x4 = 36
↓ крест-накрест ↓
x × 6 = 4 × 3
6x = 12
x = 2
🔍 Как решать линейные уравнения
  1. Раскрой скобки (если есть).
  2. Все числа с x перенеси в левую часть, числа без x — в правую.
  3. ВАЖНО: при переносе через знак «=» знак числа меняется на противоположный!
  4. Приведи подобные слагаемые.
  5. Раздели обе части на число перед x.
2x + 5 = 11
2x = 11 - 5 (переносим 5, меняем знак)
2x = 6
x = 6 / 2
x = 3
📉 Раскрытие скобок
Если перед скобкой стоит минус, все знаки внутри меняются на противоположные.

Плюс: знаки сохраняются.
a + (b - c) = a + b - c

Минус: знаки меняются.
a - (b + c) = a - b - c
🔢 Умножение скобки на число
Умножаем число на каждое слагаемое внутри скобки.
3 × (x + 4) = 3×x + 3×4 = 3x + 12
5 × (2x - 3) = 5×2x - 5×3 = 10x - 15
📊 Решение квадратных уравнений (через D)
  1. Приведи уравнение к виду ax² + bx + c = 0.
  2. Найди дискриминант: D = b² - 4ac.
  3. Если D > 0: два корня. Если D = 0: один. Если D < 0: нет корней.
  4. Корни ищем по формуле: x = (-b ± √D) / 2a.
x² - 5x + 6 = 0
a=1, b=-5, c=6
D = (-5)² - 4×1×6 = 25 - 24 = 1
x₁ = (5 + 1)/2 = 3
x₂ = (5 - 1)/2 = 2
🧮 Степени и корни
Умножение: a² × a³ = a⁵ (показатели складываются).
Деление: a⁵ / a² = a³ (показатели вычитаются).
Степень степени: (a²)³ = a⁶ (показатели умножаются).
Корень: √a × √b = √(ab).
